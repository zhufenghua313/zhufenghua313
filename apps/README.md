# apps/ — 欢乐工具站·工具仓库

每个文件夹一个工具，互不干扰。

| 目录 | 是什么 | 从哪进 |
|---|---|---|
| `gh/` | GitHub 高速平台（公众版）：免登录浏览任何人的公开仓库；登录自己的令牌就能管理自己的文件 | **gh.efcc.cc** |
| `github/` | 欢乐 GitHub 管理平台（站长私人版） | tv.efcc.cc/apps/github/admin.html |
| `share/` | 文件共享站：上传文件生成提取码，别人凭码取件 | tv.efcc.cc/share |
| `sports/` | 运动会管理系统：报名、计分、汇总（建设中） | tv.efcc.cc/soft/sports |
| `platform/` | 程序制作平台：造积木、搭程序（建设中） | tv.efcc.cc/soft/platform |
| `station-admin/` | 工具站后台：改密码、改导航 | tv.efcc.cc/apps/station-admin |

> 未列出的目录为内部用途，不对外开放。

一句话记住两兄弟：
- **`gh`**（短）= 大家用的，走 gh.efcc.cc
- **`github`**（长）= 站长自己用的，走 tv.efcc.cc
